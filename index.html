How syncing works

Both phones join the same code and talk directly to each other — no account, no server storing your list. Keep the app open on both phones while shopping for instant updates. If one phone is offline, use "Copy list as text" and send it manually.

Install it like an app: open this page in Safari, tap Share, then "Add to Home Screen". It gets its own icon and opens fullscreen.
